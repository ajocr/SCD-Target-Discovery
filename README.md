# SCD-Target-Discovery

## Description

Data-driven identification and prioritization of underexplored therapeutic targets for fetal hemoglobin reactivation in sickle cell patients

## Research Questions

1. What is the current therapeutic landscape for HbF reactivation: gene therapy vs small molecule approaches?
2. How does genetic evidence and bioactivity data for KLF1 and c-Myb compare to BCL11A as drug targets?
3. Beyond BCL11A, which HbF-regulating targets show the strongest druggability potential with an acceptable safety profile?
